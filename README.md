# 🏎️ RZ Motors - Premium Automotive Experience

> "A Perfeição Em Movimento."

Este projeto é um website **Premium e Imersivo** desenvolvido para um stand automóvel de luxo (fictício/demo baseado na RZ Motors Porto). O foco principal é a **Experiência do Utilizador (UX)**, utilizando tecnologias web modernas para transmitir velocidade, elegância e futurismo.

## 🌟 Funcionalidades Principais

* **Fundo 3D Interativo:** Um sistema de partículas fluídas ("Liquid Aerodynamics") criado com **Three.js** que simula o fluxo de ar e velocidade.
* **Carrossel "Gaming Style":** Apresentação do stock de viaturas utilizando **Swiper.js** com efeito *Coverflow* 3D, inspirado em menus de jogos de corridas.
* **Preloader Cinemático:** Animação de entrada com efeito *Motion Blur* para simular alta velocidade.
* **Simulador Financeiro:** Calculadora de crédito automóvel em tempo real.
* **Design Responsivo:** Menu mobile tipo "Hambúrguer" e adaptação total a telemóveis e tablets.
* **Dark Mode Nativo:** Interface escura para realçar as fotografias das viaturas.

## 🛠️ Tecnologias Utilizadas

* **HTML5 & CSS3** (Flexbox, Grid, Animações CSS)
* **JavaScript** (ES6+)
* **[Three.js](https://threejs.org/)** (Renderização 3D WebGL)
* **[Swiper.js](https://swiperjs.com/)** (Sistema de Sliders Táctil)
* **Google Fonts** (DM Sans & Space Grotesk)

### Parte 2: Como colocar no GitHub (Passo-a-Passo)

Vou ensinar-te a maneira mais simples, que é através do **Site do GitHub** (não precisas de usar comandos complicados no terminal).

#### 1. Prepara a tua pasta
Certifica-te de que a tua pasta `rz-motors-premium` tem lá dentro:
* Os 5 ficheiros `.html`
* O `style.css`
* O `script.js`
* O `README.md` que acabaste de criar.
* *(Se tiveres pasta de imagens, verifica se está lá também)*.

#### 2. Cria o Repositório
1.  Vai a [github.com](https://github.com/) e faz login.
2.  No canto superior direito, clica no **`+`** e escolhe **"New repository"**.
3.  **Repository name:** Escreve `rz-motors-premium` (ou o que preferires).
4.  **Public/Private:** Escolhe **Public** (para poderes ativar o site grátis).
5.  Clica em **"Create repository"**.

#### 3. Faz Upload dos Ficheiros
1.  Na página que apareceu, procura um link pequeno que diz: **"uploading an existing file"**.
2.  Arrasta **todos os ficheiros** da tua pasta para a caixa cinzenta no site.
3.  Espera que carreguem.
4.  Cá em baixo, onde diz "Commit changes", escreve: "Versão final do site".
5.  Clica no botão verde **"Commit changes"**.

#### 4. 🏆 O "Truque" Final: Colocar o site Online (GitHub Pages)
Agora que o código está guardado, vamos transformar isso num **Link Real** para mandares aos teus amigos/clientes.

1.  No teu repositório, clica na aba **Settings** (lá em cima).
2.  No menu da esquerda, clica em **Pages**.
3.  Onde diz **"Branch"**, muda de `None` para `main` (ou `master`).
4.  Clica em **Save**.

Agora espera cerca de 1 a 2 minutos. Atualiza a página.
Vai aparecer uma barra no topo a dizer:
> **"Your site is live at: [https://o-teu-user.github.io/rz-motors-premium/](https://o-teu-user.github.io/rz-motors-premium/)"**

Pronto! Agora tens um link profissional, seguro e gratuito com o teu site 3D a funcionar perfeitamente. 🚀
